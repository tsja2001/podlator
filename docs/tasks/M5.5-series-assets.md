## 0. 背景与边界

现状每期独立生成：解说者人设每期飘、同一术语（inference）这期译「推理」下期译「推断」、无法说「我们上期聊过…」。本任务加一层**可选注入**的栏目资产解决，缺资产时优雅降级（行为同现在）。

### 范围（明确不要做的事）
- ❌ **不写死人设措辞**：`series.md` 的栏目名、口头禅、自称是**产品决策**，执行者只建**带占位符的脚手架**，真实措辞由统筹者填（CLAUDE.md：prompt 措辞要问用户）。执行者**不得自行编造品牌口吻**。
- ❌ **不改** digest/research/review 逻辑；只给 blueprint/finalize 加一个可选注入槽。
- ❌ 资产缺失**绝不报错**——返回空串、log.info，链路照常（这是硬要求）。
- ❌ unit/integration 不调真实 API；真实只在 manual 跑一期人工看跨期引用是否自然。

### 1.2 `src/podlator/steps/series_context.py`（新建）
```python
def load_series_context(series_dir: Path | None) -> str:
    """读 series.md + glossary.md + episodes.md，拼成注入 prompt 的栏目设定块。

    - series_dir 为 None / 不存在 → 返回 ""，log.info("series_context_missing", dir=...)
    - 单个文件缺失 → 跳过该部分，不报错（部分资产也能用）
    - 三部分都缺 → 返回 ""
    返回格式（非空时）：
        ## 栏目设定（口播时遵守）
        <series.md 正文>
        ## 术语统一译法（出现时按此，首次仍白话化）
        <glossary.md 正文>
        ## 往期选题（可自然引用，勿重复选题）
        <episodes.md 正文>
    """


def append_episode(series_dir: Path | None, title: str, core_point: str) -> None:
    """向 episodes.md 追加一行 '- <title>：<core_point>'。
    series_dir 为 None / 不存在 → log.info 跳过，不报错（不是失败）。
    core_point 为空 → 只写标题。"""
```

## Phase 2: prompt 槽位 + 接入公共 step

### 2.1 prompt 增 `{series_context}` 槽
`douyin_blueprint.md` user prompt 顶部（「## 节目信息」之前）加：
```markdown
{series_context}
```
`douyin_finalize.md` user prompt 顶部（「## 节目信息」之前）同样加 `{series_context}`。

## Phase 3: CLI 接入 + 自动追加往期

### 3.1 `pipeline-douyin`（和 `douyin-script`）加 `--series-dir`
```python
series_dir: Annotated[Path | None, typer.Option("--series-dir",
    help="栏目资产目录（默认自动探测 project/series/）")] = None,
```
逻辑：
- 解析 series_dir：显式传 → 用；否则探测 `project/series/`（存在则用，否则 None）。
- `ctx = load_series_context(series_dir)`，传入 `generate_blueprint(..., series_context=ctx)` 和 `finalize_from_blueprint(..., series_context=ctx)`。
- 生成成功后 `append_episode(series_dir, title, core_point)`：`core_point` 尽力从 blueprint 第四部分第一个「核心观点」提取（提取不到就空，只记标题）。给个内部 helper `_extract_core_point(blueprint) -> str`（best-effort，正则找第一个「核心观点：」后的文本；找不到返回 ""）。
