## Phase 1: YtDlp Downloader Provider

### 1.1 创建 `src/podlator/providers/downloader/ytdlp.py`

实现 `YtDlpDownloader` 继承 `DownloaderProvider`。

**`fetch_metadata(url)` 实现要点：**
- 使用 `yt_dlp.YoutubeDL` 的 `extract_info(url, download=False)` 获取元数据
- 在线程池中运行（yt-dlp 是同步库）：`asyncio.get_event_loop().run_in_executor(None, ...)`
- 提取字段映射：
  - `info["title"]` → `title`
  - `info.get("description", "")` → `description`
  - `info["duration"]` → `duration_seconds`
  - `info.get("upload_date", "")` → `published_at`（格式转换 `YYYYMMDD` → ISO 8601）
  - `info.get("thumbnail", "")` → `thumbnail_url`
  - 根据 URL 判断 `source_type`："youtube" 或 "podcast_rss"
- 日志：`log.info("metadata_fetched", title=..., duration_seconds=...)`
- 异常处理：捕获 `yt_dlp.utils.DownloadError`，包装为 `ProviderError`

**`download(url, output_dir, audio_format)` 实现要点：**
- `yt_dlp.YoutubeDL` 配置：
  ```python
  ydl_opts = {
      "format": "bestaudio/best",
      "outtmpl": str(output_dir / "audio.%(ext)s"),
      "postprocessors": [{
          "key": "FFmpegExtractAudio",
          "preferredcodec": audio_format,
      }],
      "quiet": True,
      "no_warnings": True,
  }
  ```
- 同样在线程池中运行
- 下载后查找实际文件（因为 yt-dlp 可能改扩展名）
- 返回 `DownloadResult(file_path=..., format=..., size_bytes=..., duration_seconds=...)`
- 日志：`log.info("audio_downloaded", path=..., size_bytes=..., duration_seconds=...)`

## Phase 2: Deepgram STT Provider

### 2.1 创建 `src/podlator/providers/stt/deepgram.py`

实现 `DeepgramProvider` 继承 `STTProvider`。

**`transcribe(audio_path, language, diarize)` 实现要点：**
- 使用 `deepgram` SDK 的 `PreRecordedClient`
- 配置：
  ```python
  from deepgram import DeepgramClient, PrerecordedOptions
  
  options = PrerecordedOptions(
      model=self.model,        # 从 config 读取，默认 "nova-3"
      language=language,
      smart_format=True,
      diarize=diarize,
      utterances=True,         # 按语句切分
      punctuate=True,
  )
  ```
- 用 `client.listen.rest.v("1").transcribe_file(payload, options)` 发送音频
- 解析返回结果，将 Deepgram 的 words/utterances 转换为 `list[TranscriptSegment]`
- **segment 拼接逻辑**：将连续相同 speaker 的 words 合并为一个 segment
- 计算 `cost_usd`：Deepgram Nova-3 价格约 $0.0043/分钟（参考官网，写到常量里）
- 计算 `duration_ms`：记录 API 调用耗时（用 `time.perf_counter()`）
- 日志：
  - `log.info("stt_completed", provider="deepgram", audio_duration_seconds=..., segments_count=..., cost_usd=..., duration_ms=...)`
- 异常处理：
  - Deepgram SDK 异常 → `ProviderError("deepgram", ..., retryable=True/False)`
  - 超时 → `ProviderError(retryable=True)`

**构造函数**：
```python
def __init__(self, api_key: str, model: str = "nova-3"):
    self.client = DeepgramClient(api_key)
    self.model = model
```

## Phase 3: DeepSeek LLM Provider

### 3.1 创建 `src/podlator/providers/llm/deepseek.py`

实现 `DeepSeekProvider` 继承 `LLMProvider`。

**`complete(prompt, system, temperature, max_tokens)` 实现要点：**
- 使用 `openai.AsyncOpenAI` SDK（DeepSeek 使用 OpenAI 兼容 API）
- 构造函数：
  ```python
  def __init__(self, api_key: str, base_url: str, model: str, max_tokens: int = 8192):
      self.client = openai.AsyncOpenAI(api_key=api_key, base_url=base_url)
      self.model = model
      self.default_max_tokens = max_tokens
  ```
- 调用：
  ```python
  messages = []
  if system:
      messages.append({"role": "system", "content": system})
  messages.append({"role": "user", "content": prompt})
  
  response = await self.client.chat.completions.create(
      model=self.model,
      messages=messages,
      temperature=temperature,
      max_tokens=max_tokens or self.default_max_tokens,
  )
  ```
- 解析返回：
  - `response.choices[0].message.content` → `content`
  - `response.usage.prompt_tokens` → `tokens_in`
  - `response.usage.completion_tokens` → `tokens_out`
- 计算 `cost_usd`：DeepSeek V4-Flash 价格极低，写在常量或 config 中
  - 参考 DeepSeek 官网定价计算：`(tokens_in * price_per_input + tokens_out * price_per_output)`
- 日志：`log.info("llm_completed", provider="deepseek", model=..., tokens_in=..., tokens_out=..., cost_usd=..., duration_ms=...)`
- 异常处理：
  - `openai.APIError` / `openai.RateLimitError` → `ProviderError(retryable=True)`
  - `openai.AuthenticationError` → `ProviderError(retryable=False)`

### 3.2 创建 `src/podlator/providers/llm/claude.py`

实现 `ClaudeProvider` 继承 `LLMProvider`。

**与 DeepSeekProvider 几乎相同**（都用 OpenAI SDK），区别：
- `base_url` 不同（`https://api.b.ai/v1`）
- `model` 不同（`claude-opus-4.7`）
- `default_max_tokens` 不同（4096）
- `cost_usd` 计算公式不同（Claude 价格参考第三方平台定价）
- `provider_name` 返回 `"claude"`

> **可选优化**：如果两个 Provider 代码高度重复，抽取一个 `OpenAICompatibleProvider` 基类。
> 但 M1 阶段先不做这个优化，保持简单直接。M3 可以重构。

## Phase 4: Provider 注册与工厂函数

### 4.1 创建 Provider 工厂

在各 Provider 的 `__init__.py` 中添加工厂函数，根据配置返回具体实现。

**`src/podlator/providers/stt/__init__.py`**：
```python
from podlator.config import Settings

def get_stt_provider(settings: Settings) -> STTProvider:
    if settings.stt_provider == "deepgram":
        from podlator.providers.stt.deepgram import DeepgramProvider
        return DeepgramProvider(api_key=settings.deepgram_api_key, model=settings.deepgram_model)
    raise ConfigError(f"Unknown STT provider: {settings.stt_provider}")
```

**`src/podlator/providers/llm/__init__.py`**：
```python
def get_llm_provider(provider_name: str, settings: Settings) -> LLMProvider:
    if provider_name == "deepseek":
        from podlator.providers.llm.deepseek import DeepSeekProvider
        return DeepSeekProvider(
            api_key=settings.deepseek_api_key,
            base_url=settings.deepseek_base_url,
            model=settings.deepseek_model,
            max_tokens=settings.deepseek_max_tokens,
        )
    if provider_name == "claude":
        from podlator.providers.llm.claude import ClaudeProvider
        return ClaudeProvider(
            api_key=settings.claude_api_key,
            base_url=settings.claude_base_url,
            model=settings.claude_model,
            max_tokens=settings.claude_max_tokens,
        )
    raise ConfigError(f"Unknown LLM provider: {provider_name}")
```

**`src/podlator/providers/downloader/__init__.py`**：
```python
def get_downloader(settings: Settings) -> DownloaderProvider:
    from podlator.providers.downloader.ytdlp import YtDlpDownloader
    return YtDlpDownloader()
```
