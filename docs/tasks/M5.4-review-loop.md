# M5.4 — 审稿循环 + 事实核查（自动改稿到达标）

> **执行者注意**：开始前先读 `docs/tasks/EXECUTION-FRAMEWORK.md`、`CLAUDE.md`（第 7、9、13 章）、`docs/tasks/M5-overview.md`、`docs/tasks/M5.1-eval-system.md`、`docs/tasks/M5.3-research.md`、本任务书。
>
> ⚠️ **本任务书基于 M5.1/M5.2/M5.3 的契约编写**（`evaluate_script` 返回 `(JudgeReport, LintStats)`；`generate_blueprint`/`finalize_from_blueprint` 是 M5.3 拆出的公共 step；`ResearchDocument`）。**开始前确认 M5.3 已合入**，并核对这些签名与本书一致，有出入先校正。
>
> 一句话目标：成稿不再一次成型就发，而是 **lint+judge+事实核查 → 修订指令 → 定点重写**，最多 2 轮，自动逼近达标；顺手**消灭定稿截断（边界 B）**、**删除破坏结尾的尾部补字回路**。

## 0. 背景与边界

三个现状问题在此收口：
1. judge（M5.1）已能评分产指令，但没接进生产——本任务让成稿真的按指令改。
2. 外部知识有了素材卡（M5.3），但**没人查成稿是否忠实使用/有没有编造**——本任务加事实核查比对。
3. 字数不足靠 `_supplement_words_loop` 尾部追加，**破坏已收束的结尾**（rubric v3 明确扣分）——本任务删掉它，改由 lint 检出 → 修订指令 → 定点重写。

**完整链路在本任务闭合**：

```
digest → blueprint → research → finalize → ┌─ review(lint+judge+factcheck) ─┐
                                           │   verdict=needs_revision &轮<2  │
                                           └────── revise（定点重写）────────┘→ 终稿 + *.review.json
```

### 范围（明确不要做的事）
- ❌ **不改** rubric / judge / lint 内部逻辑（M5.1）；只**组合调用** `evaluate_script`。
- ❌ **不改** research 查证逻辑（M5.3）；只**消费** `ResearchDocument` 做比对。
- ❌ **不做**节目化资产 `{series_context}`（M5.5，可并行）。
- ❌ 修订**禁止全文重写推翻已合格部分**——指令定位到节，prompt 强约束「只改指向处，其余原样」。
- ❌ unit/integration 不调真实 API；真实全链路只在 manual 验收一期（见费用规约）。

## Phase 1: 边界 B —— 消灭定稿截断（先做，独立可验证）

### 1.1 `douyin_script.py`：finalize 显式传 max_tokens

```python
def _finalize_max_tokens(target_words: int) -> int:
    """中文 1 字 ≈ 1.5–2 token；按 target_words×2.5 估算输出上限，下限 8192。
    （deepseek 默认上限已由 M5.0 提到 32768，覆盖 6000 字定稿绰绰有余。）"""
    return max(8192, int(target_words * 2.5))
```

改 `_complete_with_fallback`：新增参数 `max_tokens: int`，传给主/降级两个 `provider.complete(..., max_tokens=max_tokens)`（现状两处都没传，导致降级到 API 时被默认上限腰斩——这就是边界 B）。

`finalize_from_blueprint`（M5.3 已公开）内：`mt = _finalize_max_tokens(target_words)`，调用传入；拿到结果后：

```python
if result.finish_reason == "length":
    log.warning("finalize_truncated", max_tokens=mt, target_words=target_words,
                tokens_out=result.tokens_out)
    # 重试 1 次，max_tokens 翻倍；仍 length 则告警返回（交给 review 的截断探针兜底）
```

## Phase 3: 数据模型 + 事实核查

### 3.1 `models.py`（追加）
```python
class ReviewReport(BaseModel):
    """一轮评审的完整结果 — 落盘 *.review.json。"""

    round: int                                   # 第几轮（0=首评，1/2=修订后复评）
    judge: JudgeReport                           # M5.1 评分（已含 judge+lint 合并指令）
    lint: LintStats
    fact_check_directives: list[RevisionDirective] = Field(default_factory=list)
    revision_directives: list[RevisionDirective]  # 最终合并 = judge.revision_directives + fact_check
    verdict: Literal["pass", "needs_revision"]
```
`io.py` 追加 `write_review`（读用不到，可只写）。

### 3.2 `steps/fact_check.py`（新建）
```python
async def fact_check_script(
    script: str, research: ResearchDocument | None, *,
    provider_name: str | None = None,   # None → settings.llm_provider_judge（便宜）
    settings: Settings | None = None,
) -> list[RevisionDirective]:
    """检出成稿里"访谈之外的事实声明"中、素材卡无法支撑的，生成"删除或改写"指令。

    - research 为 None 或 cards 为空 → 返回 []，log.info("fact_check_skipped_no_research")
      （宁缺毋滥的 finalize 已最小化外部声明；无卡可比时不强行删）
    - 否则调便宜模型：prompt 给 script + 素材卡所有 claim/source，
      要求列出"稿中作为事实陈述、但素材卡里找不到对应来源"的外部声明
    - 每条 → RevisionDirective(target=稿中该声明附近, problem="外部事实无素材卡支撑",
      instruction="删除该声明，或改写为不依赖未证实外部事实的表述")
    - 解析失败重试 1 次再失败 → 返回 []（事实核查失败不该卡死 pipeline）+ log.warning
    """
```
prompt `fact_check.md`：system=严格事实核查员；输入 script + 卡片 claims；**只输出 JSON 数组**，每项 `{claim_in_script, problem, instruction}`；稿中所有外部事实都能在卡里找到 → 输出 `[]`。

## Phase 4: review + revise + 循环

### 4.1 `steps/review_script.py`（新建）
```python
async def review_script(
    script: str, *, research: ResearchDocument | None = None,
    reference_points: str | None = None, target_words: int | None = None,
    rubric_version: str = "v3", round: int = 0, settings: Settings | None = None,
) -> ReviewReport:
    """组合 M5.1 judge + 事实核查 → ReviewReport。

    judge, lint = await evaluate_script(script, reference_points=..., target_words=...,
                                        rubric_version=..., settings=...)
    fact = await fact_check_script(script, research, settings=...)
    merged = list(judge.revision_directives) + fact
    # 事实核查发现硬伤 → 即便 judge pass 也下调为 needs_revision
    verdict = "needs_revision" if (judge.verdict == "needs_revision" or fact) else "pass"
    return ReviewReport(round=round, judge=judge, lint=lint,
                        fact_check_directives=fact, revision_directives=merged, verdict=verdict)
    """
```

### 4.2 `revise_script`（放 `steps/revise_script.py`）
```python
async def revise_script(
    draft: str, directives: list[RevisionDirective], *,
    blueprint: str, research: ResearchDocument | None,
    title: str, speakers: str, target_words: int,
    provider_name: str, settings: Settings | None = None,
) -> str:
    """finalize provider 据"草稿 + 修订指令"定点重写全稿。
    - 显式 max_tokens=_finalize_max_tokens(target_words)（复用 Phase 1，边界 B）
    - finish_reason=="length" → log.warning + 重试 1 次更大上限
    - prompt 强约束：只改指令指向处，其余原样保留，输出**完整全稿**（不是 diff、不是片段）
    - 外部知识仍只能用素材卡（research）
    """
```
prompt `revise_script.md`：system 强调「定点修订、保留合格部分、输出完整全稿、外部知识只用素材卡、不得在结尾后追加游离段落」；user 注入 `{draft}`、`{directives}`（编号列出 target/problem/instruction）、`{blueprint}`、`{research_cards}`。

### 4.3 循环编排 `review_and_revise`（放 `steps/review_script.py`）
```python
async def review_and_revise(
    draft: str, *, research: ResearchDocument | None, blueprint: str,
    title: str, speakers: str, target_words: int,
    reference_points: str | None = None, finalize_provider: str,
    settings: Settings | None = None, max_rounds: int = 2,
) -> tuple[str, ReviewReport]:
    """评审→修订循环，最多 max_rounds 轮。
    review = review_script(draft, round=0, ...)
    rounds = 0
    while review.verdict == "needs_revision" and rounds < max_rounds:
        rounds += 1
        draft = await revise_script(draft, review.revision_directives, ...)
        review = await review_script(draft, round=rounds, ...)
    return draft, review     # 终稿 + 最终一轮 ReviewReport
    """
```
日志：每轮 `log.info("review_round", round=..., verdict=..., total_score=..., num_directives=...)`；达标或满轮 `log.info("review_loop_done", rounds=..., final_verdict=...)`。
